# Prints do Torneio

20 capturas reais da aplicação, com versões claras e escuras de cada tela. Os arquivos JPEG preservam a captura original do navegador.

As imagens foram feitas em 04/10/2026, em uma cópia local da aplicação com banco SQLite separado. Contas, participantes, eventos, locais de demonstração e chave Pix são fictícios. Os dados da instalação original foram preservados.

[Voltar ao README principal](../../README.md#prints-do-aplicativo).
